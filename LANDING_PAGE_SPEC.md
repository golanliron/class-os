# עיצוב כללי

## צבעים
- **רקע:** לבן (#FFFFFF) ואפור בהיר (#F8F9FA)
- **טקסט ראשי:** כהה (#1A1A2E)
- **אקסנט ראשי:** סגול-כחול (#4F46E5) — טכנולוגי, חינוכי, לא ילדותי
- **אקסנט משני:** ורוד חם (#E8358A) — לכפתורי CTA
- **ירוק הצלחה:** (#10B981) — לצ׳קמרקים וסטטוסים

## טיפוגרפיה
- **כותרות:** Heebo Black / Bold
- **גוף טקסט:** Heebo Regular
- **מספרים גדולים:** Heebo Black, 64px+

## אנימציות
- Hero: fade-in עדין מלמטה
- כרטיסי "הבעיה": stagger animation (אחד אחרי השני)
- שלבי "איך זה עובד": מופיעים בגלילה
- מספרים: counter animation (0→60)
- Screenshots: slide-in מהצד

## Responsive
- Desktop: 2-3 columns
- Tablet: 2 columns
- Mobile: 1 column, כל הטקסטים מותאמים

# מבנה טכני

```
/ (landing page - public)
/login (כניסה)
/signup (הרשמה)
/app/* (המערכת - protected)
  /app/dashboard
  /app/week
  /app/lesson/[id]
  /app/plan
  /app/class/[id]
  /app/principal/*
```

הדף השיווקי הוא **עמוד אחד** (single page) עם smooth scroll לסקשנים.
כניסה למערכת = route נפרד לגמרי עם layout אחר.
